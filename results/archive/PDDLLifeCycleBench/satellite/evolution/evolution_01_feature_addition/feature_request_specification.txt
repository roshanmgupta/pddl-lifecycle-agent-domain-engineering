BASELINE DOMAIN: SATELLITE -> EVOLVED DOMAIN: SATELLITE (TELEMETRY DOWNLINK)

REQUIREMENT SPECIFICATION (AUTOPLANBENCH NATURAL LANGUAGE ENCODING):
Extend the existing operational model of the satellite domain to incorporate downlink telemetry data transmission to ground stations.

I can carry out the following new action:
transmit image data of a direction B in a mode D using an instrument C on a satellite A pointing at a ground station E

I have the following restrictions on my actions:
I can only transmit image data of a direction B in a mode D using an instrument C on a satellite A pointing at a ground station E if it is the case that C is on board A and power is on for C and C is calibrated and C supports D and A is pointing at E and E is a ground station and B has an image of D

The actions have the following effects on the state:
Once I transmit image data of a direction B in a mode D using an instrument C on a satellite A pointing at a ground station E, it is the case that data is transmitted for the direction B in the mode D

SOLVABILITY PRESERVATION MANDATE:
All baseline actions (turning a satellite, switching instruments on and off, calibrating an instrument, and taking an image) must remain intact so that all baseline benchmark problem instances remain 100% solvable without reachability regressions.
