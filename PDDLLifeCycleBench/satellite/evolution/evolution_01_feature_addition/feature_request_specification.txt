================================================================================
CATEGORY C: CONTINUOUS DOMAIN EVOLUTION SPECIFICATION (CAPABILITY EXTENSION)
BASELINE DOMAIN: SATELLITE -> EVOLVED DOMAIN: SATELLITE (TELEMETRY DOWNLINK)
================================================================================
REQUIREMENT SPECIFICATION (AUTOPLANBENCH / CLASSICAL PLANNING GROUNDING):
Extend the existing operational model of the satellite domain to incorporate downlink telemetry data transmission to ground stations.

The baseline domain enables:
- turning a satellite from one direction to another
- switching instruments on and off on a satellite
- calibrating an onboard instrument pointing at a calibration target direction
- taking an image of a direction using an onboard calibrated instrument in a mode

CAPABILITY EXTENSION REQUIREMENTS:
1. New Predicate:
   - (ground_station ?d - direction): declares that a direction corresponds to a ground downlink receiver station.
   - (data_transmitted ?d - direction ?m - mode): tracks whether the acquired image data for direction ?d in mode ?m has been successfully downlinked.

2. New Action Schema:
   - Name: transmit_image_data
   - Parameters:
     ?s - satellite, ?i - instrument, ?d - direction, ?g - direction, ?m - mode
   - Preconditions:
     The instrument ?i must be on board satellite ?s, power must be on for ?i, ?i must be calibrated, ?i must support mode ?m, the satellite ?s must be pointing at ground station direction ?g, direction ?g must be a ground station (ground_station ?g), and the satellite must have captured the image of direction ?d in mode ?m (have_image ?d ?m).
   - Effects:
     Asserts that image data for direction ?d in mode ?m has been transmitted: (data_transmitted ?d ?m).

SOLVABILITY PRESERVATION MANDATE:
All baseline action schemas (turn, switch_on, switch_off, calibrate, take_image) must remain intact so that all baseline benchmark problem instances remain 100% solvable without reachability regressions.
