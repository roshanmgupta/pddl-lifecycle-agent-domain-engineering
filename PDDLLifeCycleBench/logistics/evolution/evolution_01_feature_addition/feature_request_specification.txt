BASELINE DOMAIN: LOGISTICS -> EVOLVED DOMAIN: LOGISTICS (INTER-VEHICLE CROSS-DOCKING)
================================================================================
REQUIREMENT SPECIFICATION (AUTOPLANBENCH NATURAL LANGUAGE ENCODING):
Extend the existing operational model of the logistics domain to support direct inter-vehicle cargo cross-docking between co-located transport trucks.

I can carry out the following new action:
cross load an object A from a truck B into a truck C at a location D

I have the following restrictions on my actions:
I can only cross load an object A from a truck B into a truck C at a location D if it is the case that A is an obj and B is a truck and C is a truck and D is a location and B is at D and C is at D and A is in B

The actions have the following effects on the state:
Once I cross load an object A from a truck B into a truck C at a location D, it is the case that A is in C
Once I cross load an object A from a truck B into a truck C at a location D, it is not the case anymore that A is in B

SOLVABILITY PRESERVATION MANDATE:
All baseline actions (loading and unloading trucks and airplanes, driving trucks, and flying airplanes) must remain intact so that all baseline benchmark problem instances remain 100% solvable without reachability regressions.
