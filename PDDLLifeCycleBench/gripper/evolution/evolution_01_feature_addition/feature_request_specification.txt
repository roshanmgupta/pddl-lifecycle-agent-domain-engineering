CATEGORY C: CONTINUOUS DOMAIN EVOLUTION SPECIFICATION (CAPABILITY EXTENSION)
BASELINE DOMAIN: GRIPPER -> EVOLVED DOMAIN: GRIPPER (COOPERATIVE INTER-ROBOT TRANSFER)
================================================================================
REQUIREMENT SPECIFICATION (AUTOPLANBENCH NATURAL LANGUAGE ENCODING):
Extend the existing operational model of the multi-robot gripper domain to support direct cooperative inter-robot object transfers.

I can carry out the following new action:
cooperatively transfer an object C from a robot A using a gripper D to a robot B using a gripper E in a room F

I have the following restrictions on my actions:
I can only cooperatively transfer an object C from a robot A using a gripper D to a robot B using a gripper E in a room F if it is the case that A is at F and B is at F and A is carrying C to D and B is free from E

The actions have the following effects on the state:
Once I cooperatively transfer an object C from a robot A using a gripper D to a robot B using a gripper E in a room F, it is the case that B is carrying C to E and A is free from D
Once I cooperatively transfer an object C from a robot A using a gripper D to a robot B using a gripper E in a room F, it is not the case anymore that A is carrying C to D and it is not the case anymore that B is free from E

SOLVABILITY PRESERVATION MANDATE:
All baseline actions (moving between rooms, picking objects with a gripper, and dropping objects in a room) must remain intact so that all baseline benchmark problem instances remain 100% solvable without reachability regressions.
